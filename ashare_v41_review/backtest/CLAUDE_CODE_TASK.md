## 0 环境
- Python ≥3.10;`pip install pandas numpy pyyaml openpyxl matplotlib`;数据库非 SQLite 时再装 `sqlalchemy` 和驱动。
- 只读访问数据库;所有产物写到 `out/`,并把每次运行的 config、git/commit 标识、随机种子记入 `out/run_log.md`。

## 1 摸清数据库(产出 `out/db_schema.md`)
逐项查清并写明:
1. **日 K 表**:字段名、复权方式(前复权/后复权/复权因子)、覆盖区间、是否含**已退市、ST、停牌**股票(缺则存在幸存者偏差,必须明说)。
2. **资金流历史**:是否存在逐日逐股"主力净流入/小单净流入"历史?起止日期?单位(元/万元)?数值是**收盘终值**还是盘中快照?口径是否随时间变更?
   - 若历史不足 2 年:E1~E8 无法给出可靠结论 → 报告缺口,改用"前向跟踪 + 已有 60 日快照"并停止下文,**不要用 `当日×3` 之类估算补数据**。
3. 行业(申万一级)、指数(沪深300/中证500/中证1000/全A 等权)、交易日历。
4. 找到生产选股脚本(如 `v4_*.py`、`run_*.py`),确认 V4.1 的**精确**子因子公式。

## 2 填写 `config.yaml` 并做数据体检
- 从 `config.example.yaml` 复制,逻辑字段不动,只改物理列名;`mktcap` 单位必须是**亿元**,`main_net/small_net` 单位必须是**元**(不是就在 SQL 里换算)。
- 运行 `python run_backtest.py --config config.yaml --exp E1 --out out/` 的第一屏就是**数据体检**。必须满足:
  缺失率 <2%;`|main_net|>amount` 占比≈0;单日涨跌幅>25% 占比≈0;股票数 ≫ 现存数(含退市);OHLC 自洽。不满足先修数据。

## 3 对齐 V4.1 生产评分(消除复刻偏差)
- `bt/strategies.py::V41_HOOK` 默认 None(用文字口径复刻)。请把生产脚本里"初筛→质量门→C4→四维分→Overheat→修正综合分"封装成
  `fn(P, F) -> (score: DataFrame日期×代码, eligible: DataFrame bool)` 赋给 `V41_HOOK`。
- 验收:任取 5 个历史交易日,用生产脚本与 HOOK 各算一遍,**前 60 名重合率 ≥95%**;否则继续对齐。

## 4 自检(必须全部 PASS)
`python selftest.py`。随后用**真实数据**再做两项:
- **截断不变性**:截断到某日 T 重算,T 日信号必须与全样本一致(selftest 里已有模板,请对真实数据重做)。
- **时点检查**:抽 10 只股票,核对 T 日用到的所有字段都是 T 日收盘后才可得(尤其资金流、市值、ST 标记、行业)。

## 5 运行实验(严格顺序,每个门槛过了才进下一个)

## 6 纪律
- **样本划分写死**:训练 2021-01~2024-12(或库内最早),验证 2025,样本外 2026-01-05~最新。样本外只在最终方案冻结后跑一次。
- **记录试验次数**:每改一次规则/参数网格,在 `out/trials.csv` 追加一行;最终报告用总数计算通缩夏普。
- 不得使用未来信息、不得因看到样本外结果回头改规则、不得删除亏损区间。
- 回测成本用保守口径:佣金万 2.5、印花税 0.05%(卖)、过户费 0.001%、滑点≥10bp、20 日成交额 5% 容量上限;并报告滑点 20/30bp 的敏感性。
